Transcribe a sample recording and save the result to `transcript.txt`.

## Before you begin

You need Python 3.11+ and an [AssemblyAI API key](https://www.assemblyai.com/dashboard) with available credits. Run the following commands in a terminal.

## 1. Install the SDK

Create a project and a virtual environment:

```bash
mkdir assemblyai-demo
cd assemblyai-demo
python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade assemblyai
```

On Windows, use `py` instead of `python3` to create the environment, then activate it with `.venv\Scripts\Activate.ps1` in PowerShell.

## 2. Set your API key

In the same terminal, replace the placeholder with your key:

```bash
export ASSEMBLYAI_API_KEY="your-api-key"
```

In PowerShell, use `$env:ASSEMBLYAI_API_KEY="your-api-key"`. Keep the key out of your source files and Git.

## 3. Transcribe an audio file

Save this code as `transcribe.py`:

```python
import os
from pathlib import Path

from assemblyai import TranscriptStatus
from assemblyai.prerecorded.v2 import Transcriber

api_key = os.environ.get("ASSEMBLYAI_API_KEY")
if not api_key:
    raise SystemExit("Set ASSEMBLYAI_API_KEY in this terminal first.")

transcriber = Transcriber(api_key=api_key)
transcript = transcriber.transcribe("https://assembly.ai/wildfires.mp3")

print(f"Transcript ID: {transcript.id}")
if transcript.status == TranscriptStatus.error:
    raise SystemExit(f"Transcription failed: {transcript.error}")

Path("transcript.txt").write_text(transcript.text or "", encoding="utf-8")
print(transcript.text)
print("Saved transcript.txt")
```

Run it:

```bash
python transcribe.py
```

The SDK waits for the job to finish. You should see a transcript about Canadian wildfires in your terminal and a new `transcript.txt` file in your project.

To use your own recording, replace the sample URL with a local path such as `"./interview.mp3"`. The SDK uploads local files for you.

## Troubleshooting

| Problem | What to do |
| --- | --- |
| Missing API key or authentication error | Set the key in the terminal running the script. Copy it again from your dashboard if needed. |
| Import error | Activate `.venv` and run `python -m pip install --upgrade assemblyai`. Don’t name your script `assemblyai.py`. |
| Insufficient balance | Check your credits and billing in the AssemblyAI dashboard. |
| Transcription fails | Read the printed error. Use a playable audio file or a direct, publicly accessible media URL. |
